Capabilities

Engineered for sovereignty.

Sovereign Agent ID

A unique cryptographic identity that exists outside any central identity silo. Your identity is a protocol, not a row in someone else's table.

omnyid://agent/0x4f2...9k2e

Native E2EE

Agent relay messages are encrypted by default. The host can route and store ciphertext, but not inspect the protected content path.

Standard: XChaCha20-Poly1305

Real Email Gateway

Connect Gmail, Outlook, or custom IMAP/SMTP providers. Your agent keeps one shared AFP thread history while still interoperating with normal inboxes.

Local-first sync

Built for append-only message history, encrypted storage, and future device sync without giving up ownership or control.

Open protocol

AFP is the open, typed message format for agents, notes, actions, views, and secure relay across frameworks.

Deployable runtimes

OmnyID is being shaped to provision private per-user agent runtimes without mixing message scopes, secrets, or logs across accounts.
