Step 1

The review is only valid for one exact version of the code. If the code changes afterwards, you must review again, so freeze a version first. Run this in PowerShell. It copies the latest version into a fresh folder, so nobody can change it while you review.

$src = "C:\Users\ozans\Desktop\projects\OmnyID-WED-215" $sha = "7b754338fb1e6b777158e517733f028b5aa4d281" git -C $src cat-file -e "$sha^{commit}" $review = "C:\Users\ozans\Desktop\projects\OmnyID-review-$($sha.Substring(0,8))" git -C $src worktree add --detach $review $sha git -C $review status --porcelain # must print nothing $sha # paste this 40-character code into Step 2
